## Regeneration Script

Run this to produce a fresh list of manually installed packages:

```bash
apt-mark showmanual | sort > /tmp/manually-installed.txt
echo "--- Manually installed packages: $(date +%Y-%m-%d) ---"
cat /tmp/manually-installed.txt
```

Or, to diff against this file's last state:

```bash
apt-mark showmanual | sort > /tmp/current.txt
diff <(grep '^| ' linux/installed-packages.md | awk -F'|' '{gsub(/ /,"",$3); print $3}' | sort) /tmp/current.txt
```
