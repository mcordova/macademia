# 001 — Greet

Ask the user for their name and print a personalised greeting.

## Run

### Bash

```bash
bash bash/greet.sh
```

### Python

```bash
python3 python/greet.py
```

### C

```bash
gcc -o greet c/greet.c && ./greet
```

### Go

```bash
go run go/greet.go
```

### Rust

```bash
cd rust && cargo run
```

## Example

```
Enter your name: Michael
Hello, Michael!
```

## What to compare

- How each language handles stdin / user input
- String interpolation vs concatenation
- Trimming newlines from input (C, Rust)
