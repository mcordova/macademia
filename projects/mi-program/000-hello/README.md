# 000 — Hello, World!

The simplest possible program in each language: print a message to stdout.

## Run

### Bash

```bash
bash bash/hello.sh
```

### Python

```bash
python3 python/hello.py
```

### C

```bash
gcc -o hello c/hello.c && ./hello
```

### Go

```bash
go run go/hello.go
```

### Rust

```bash
cd rust && cargo run
```

### PHP

```bash
php php/hello.php
```

## Expected output

```
Hello, World!
```

## What to compare

- Lines of code
- Boilerplate / ceremony required
- Compilation vs interpretation
- Startup time
- Binary size (for compiled languages)
